# 채채의 혼밥 식당

세로형 모바일 웹 요리 게임의 개발 문서 묶음입니다. 첫 구현 범위는 **필수 계란후라이 트라이얼부터 레벨 1을 마치고 레벨 2가 열리는 화면까지**입니다. 정식 버전의 5개 레벨과 자유 영업 규칙도 함께 정의합니다.

## Codex에서 시작하기

압축을 풀고 이 README와 AGENTS.md가 있는 폴더를 Codex에서 엽니다. 아래 문장을 첫 개발 요청으로 사용하세요.

> 〈채채의 혼밥 식당〉의 첫 플레이 버전을 구현해 주세요. 루트 AGENTS.md와 docs 폴더의 PRD.md, GDD.md, FRD.md, design.md, TRD.md, PLAN.md, QA.md, DECISIONS.md를 읽고 PLAN의 M0부터 M3까지 순서대로 진행하세요. 필수 계란후라이 트라이얼과 레벨 1 세 메뉴의 조작, 평가, 재도전, 레벨 2 해금을 실제로 플레이할 수 있게 구현하세요. 스티치 시안이 있으면 design.md와 함께 반영하고, 시안 전에는 교체 가능한 임시 아트를 사용하세요. QA 시나리오를 검증하고 실행 방법, 실제 검증 환경, 남은 항목을 요약해 주세요.

## 문서 기준

게임 규칙은 GDD, 화면과 상호작용은 FRD, 시각 기준은 design, 구현 방식은 TRD를 따릅니다. 사용자의 최신 결정과 문서 내용이 다르면 DECISIONS에 이유와 영향 범위를 기록하고 관련 문서를 함께 수정합니다.
