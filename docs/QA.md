## 실기기 기록

- iOS Safari와 Android Chrome에서 시작부터 레벨 2 해금까지 최소 한 차례씩 진행한다.
- 세로 폭 320·360·390·430 CSS 픽셀은 실기기와 에뮬레이션을 조합해 확인한다. 주소창 높이가 바뀌어도 타이머와 하단 서빙 버튼이 보여야 한다.
- 첫 시도에는 구두 설명을 추가하지 않고 화면의 안내만으로 진행한다. 손가락이 대상이나 다음 안내를 가리는 구간, 화면 스크롤과의 충돌, 실패 이유를 이해했는지 기록한다.
- 소리를 끈 상태에서도 익힘·탄 경고·손님 이탈을 구분하고, 모션 감소 상태에서 조작과 결과를 이해할 수 있는지 확인한다.
- 결과 기록에는 기기·OS·브라우저, 실제 기기 또는 에뮬레이션 구분, 빌드 식별자, 케이스 ID, 통과 여부, 재현 단계를 적는다.
