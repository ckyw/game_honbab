## 조작 피드백과 판정 경계

경계값은 테스트에서 조리대와 가이드 기준 좌표로 재현한다. 실기기에서는 손가락을 따라가는 미리보기, 안내 전환, 손을 뗄 때의 결과를 확인한다.

| ID | 재현 | 기대 결과 |
|---|---|---|
| Q02a · 껍질 방향과 끝 표시 | 예열이 끝난 금 간 계란에서 화살표 반대 방향으로 민다. 다시 올바른 방향으로 밀어 끝 표시 직전에 뗀다. 세 번째에는 끝 표시까지 밀어 누른 채 멈췄다가 조금 되돌아와서 뗀다. | 올바른 방향으로 민 거리만큼 양쪽 껍질이 벌어지고, 되돌리면 틈이 줄어든다. 끝 표시에서는 ‘손을 떼세요’가 보인다. 세 시도 모두 계란이 떨어지거나 익기 시작하지 않고 금 간 상태에서 다시 시도할 수 있다. |
| Q02b · 껍질 정상 종료 | 별도 주문에서 각각 느리게, 빠르게 끝 표시까지 밀고 손을 뗀다. 또 다른 시도에서는 끝 표시에서 포인터를 취소한다. | 정상 종료한 두 주문에서 각각 계란이 한 번 떨어지고 익힘 시간이 시작된다. 취소한 시도는 금 간 상태로 돌아간다. |
| Q06a · 칼질 미리보기와 중복 | 오이를 씻어 도마에 놓고, 미완료 가이드의 시작 영역에서 긋는다. 반대편까지 도달한 채 멈춘 뒤 손을 뗀다. 같은 위치를 다시 긋고 남은 두 가이드를 각각 한 번씩 자른다. | 칼과 절단선이 진행량을 따라 움직인다. 반대편에서 ‘손을 떼세요’가 보이고 조각 수는 그대로다. 손을 떼면 해당 위치에서 한 조각만 분리되고 완료 표시가 생긴다. 같은 위치를 반복해도 횟수는 늘지 않고, 세 곳을 확정하면 재료 올리기가 열린다. |
| Q06b · 칼질 무효와 취소 | 한 곳을 먼저 확정한다. 다른 위치에서 탭, 역방향 긋기, 반대편에 닿기 전 손 떼기, 가이드 범위를 벗어난 뒤 손 떼기, 반대편에 도달한 뒤 포인터 취소를 각각 시도한다. | 어느 시도도 새 조각을 만들지 않는다. 미리보기가 사라지고 미완료 가이드에서 다시 시작할 수 있다. 앞서 확정한 조각과 세척 상태는 유지된다. |
| Q06c · 칼질 정확 구간 | 별도 주문에서 가이드의 전체 범위 안을 지나되 오이 가운데를 가이드 중심에서 도마 너비의 5% 지점과 그보다 조금 바깥에서 각각 가로지른다. 나머지 두 절단은 중앙을 지나고 고추장을 넣어 두 바퀴 비빈다. | 두 긋기 모두 절단으로 인정된다. 5% 경계는 정확한 절단으로 기록되어 ★★★, 경계 밖의 유효한 절단이 하나 있으면 ★★다. |
| Q07a · 말기 55% 경계 | 55% 바로 아래에서 손을 뗀다. 재시도에서 정확히 55%까지 밀고 누른 채 멈춘 뒤 손을 뗀다. | 첫 시도는 속재료를 얹은 상태로 돌아간다. 두 번째 시도는 ‘손을 떼면 말기 완료’가 보이되 썰기가 잠겨 있고, 손을 떼는 순간 55%가 한 번 기록되며 썰기가 열린다. |
| Q07b · 말기 되돌리기와 취소 | 55%를 넘긴 뒤 55% 아래로 되돌아와 손을 뗀다. 별도 시도에서 55% 이상인 채 포인터를 취소한다. | 아래로 움직이면 말린 모양과 안내도 되돌아간다. 두 시도 모두 썰기가 열리지 않고 속재료를 얹은 상태에서 다시 시작할 수 있다. |
| Q07c · 말기 품질 경계 | 별도 주문에서 75% 바로 아래, 정확히 75%, 90% 바로 아래, 정확히 90%에서 각각 손을 뗀다. 각 주문에서 네 번 고르게 썰고 서빙한다. | 각각 ★, ★★, ★★, ★★★를 받는다. 말기 품질은 손을 뗀 시점의 값으로 평가한다. |
| Q09a · 종료와 마감 경합 | 각 조작의 유효한 손 떼기 직후 같은 입력을 중복 전달한다. 별도 시도에서는 누른 채 마감에 도달한 뒤 손을 뗀다. | 첫 시도에서 단계·횟수·익힘 시작은 조작당 한 번만 반영된다. 마감 후 손을 떼면 조작 완료나 별점 없이 시간 초과로 끝난다. |

## 실기기 기록

- iOS Safari와 Android Chrome에서 시작부터 레벨 2 해금까지 최소 한 차례씩 진행한다.
- 세로 폭 320·360·390·430 CSS 픽셀은 실기기와 에뮬레이션을 조합해 확인한다. 주소창 높이가 바뀌어도 타이머와 하단 서빙 버튼이 보여야 한다.
- 첫 시도에는 구두 설명을 추가하지 않고 화면의 안내만으로 진행한다. 손가락이 대상이나 다음 안내를 가리는 구간, 화면 스크롤과의 충돌, 실패 이유를 이해했는지 기록한다.
- 소리를 끈 상태에서도 익힘·탄 경고·손님 이탈을 구분하고, 모션 감소 상태에서 조작과 결과를 이해할 수 있는지 확인한다.
- 결과 기록에는 기기·OS·브라우저, 실제 기기 또는 에뮬레이션 구분, 빌드 식별자, 케이스 ID, 통과 여부, 재현 단계를 적는다.
