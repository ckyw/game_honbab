# STITCH_PROMPT · 첫 화면 시안

[design.md](design.md)를 시각 자료로 함께 제공하고, 아래 문단부터 복사해 사용하세요. 이 프롬프트는 화면과 상태를 디자인하기 위한 것이며, 조작과 판정의 구현 기준은 [FRD](FRD.md)입니다.

---

〈채채의 혼밥 식당〉의 스마트폰 세로형 웹 게임 화면 프로토타입을 만들어 주세요. 화면 텍스트는 한국어로 작성하고, 제공한 디자인 가이드의 색상, 2.5D 캐주얼 툰 스타일, 조명과 카메라 각도를 따라 주세요. 스마트폰의 한 손가락 탭, 드래그, 스와이프를 기준으로 화면을 배치해 주세요.

홀과 주방은 서로 전환되는 화면으로 디자인해 주세요. 홀은 0–10° 아이레벨 정면에서 손님의 얼굴과 주문 말풍선이 중심입니다. 주방은 60–75° 하향 부감에서 팬·도마·그릇 등 현재 조작 영역이 화면 중앙을 크게 차지하게 해 주세요. 상단에는 주문명과 남은 초, 하단에는 엄지로 누르기 쉬운 서빙 버튼을 배치해 주세요. 안전 여백과 충분한 터치 영역을 확보하고, 안내는 도구 옆에 한 문장만 표시해 주세요.

연결할 화면과 상태는 다음과 같습니다.

1. **시작과 트라이얼 홀**. 타이틀, 시작하기 버튼, 첫 손님 한 명, 계란후라이 주문 말풍선. 말풍선을 누르면 주방에 들어가며 60초가 시작됩니다.
2. **계란후라이 주방**. 화구 켜기와 팬 예열, 금이 간 껍질 한쪽을 미는 상태, 익어가는 흰자와 소금통, 뒤집개와 접시의 상태를 보여 주세요. 한 손가락 방향을 도구 옆에 표시해 주세요.
3. **서빙과 평가**. 같은 홀 시점에서 손님 반응, 별점, 개선할 행동 한 줄을 표시해 주세요. 예시 문구는 ‘흰자가 익고 간이 딱 맞아요!’와 ‘조금 탔어요. 다음에는 조금 일찍 옮겨보세요.’입니다. 시간이 다 된 경우는 별점 대신 손님이 떠난 상태와 다음 동작을 보여 주세요.
4. **레벨 1 홀과 주방**. 첫 주문은 계란후라이, 비빔밥, 김밥 순서입니다. 비빔밥 화면에는 수전과 채소, 도마, 비비는 그릇을, 김밥 화면에는 밥 펴기, 김발 말기와 썰기 상태를 보여 주세요. 활성 도구가 바뀌어도 주문명, 타이머, 서빙 버튼의 위치는 일관되게 유지해 주세요.
5. **레벨 2 해금**. 레벨 1의 세 메뉴가 각각 별 2개 이상으로 통과했다는 상태와 라면·떡볶이·돈가스가 열렸다는 안내를 보여 주세요.

시간은 주방에서만 줄고, 평가 화면에서 다음 주문을 고르기 전까지 대기 손님의 시간은 줄지 않습니다. 주방에서는 시간이 충분할 때, 얼마 남지 않았을 때, 시간이 끝났을 때를 구분해 주세요. 게이지 색상에 남은 초와 안내 문구를 함께 사용해 주세요.

대표 모바일 세로 프레임은 390×844로 잡되 더 좁은 폭에도 맞게 구성해 주세요. 주문 말풍선, 타이머, 안내, 도구, 평가 카드는 이후 웹 구현에서 재사용할 수 있는 일관된 형태로 만들어 주세요.
