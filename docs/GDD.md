# GDD · 게임 규칙

## 기본 흐름

1. 손님 한 무리가 함께 입장해 주문을 표시한다. 한 무리의 모든 손님이 서빙받거나 시간 초과로 떠난 뒤 다음 무리가 들어온다.
2. 말풍선이나 대기열 카드를 눌러 주문을 선택한다. 주방이 비어 있을 때 선택한 접시가 주방에 들어가며 해당 주문의 타이머가 시작된다.
3. 한 번에 한 접시만 조리한다. 대기 중인 주문의 시간은 줄지 않는다. 서빙 또는 시간 초과로 활성 주문을 끝내고, 평가 또는 이탈 상태를 확인한 뒤 다음 주문을 직접 선택한다.
4. 완성한 접시는 품질이 낮아도 서빙할 수 있다. 시간 초과는 평가 없는 이탈이다. 서빙이 제시간에 접수되면 결과 연출 중 타이머는 멈춰 있다.

## 트라이얼과 레벨 1

- 첫 손님은 계란후라이를 주문한다. 60초 안에 흰자를 익히고 적절히 간해 통과한다. 조금 탄 음식은 서빙 가능하며 낮은 평가를 받는다. 낮은 평가나 시간 초과 뒤에는 트라이얼을 다시 시작할 수 있다.
- 통과 후 레벨 1이 시작된다. 트라이얼은 레벨 1 계란후라이 통과로 합산하지 않는다.
- 레벨 1 최초 주문은 **계란후라이 → 비빔밥 → 김밥**이다. 앞 메뉴를 놓쳐도 남은 첫 주문은 순서대로 나온다.
- 최초 세 주문이 끝나면 미통과 메뉴만 순서대로 다시 제시한다. 세 메뉴 모두 별 2개 이상이면 레벨 2가 열린다.

## 레벨과 메뉴

| 레벨 | 조리 제한 시간 | 한 무리 최대 인원¹ | 새 메뉴 |
|---|---:|---:|---|
| 1 | 60초 | 1명 | 계란후라이, 비빔밥, 김밥 |
| 2 | 55초 | 2명 | 라면, 떡볶이, 돈가스 |
| 3 | 50초 | 4명 | 생선구이, 쌀국수, 피자 |
| 4 | 45초 | 7명 | K-치킨, 오징어볶음, 스테이크 |
| 5 | 40초 | 10명 | 랍스터, 조개구이, 해물탕 |

¹ 최대 10명과 무리 입장은 합의했고, 중간 레벨 인원은 앞서 제안한 튜닝 기본값이다.

## 주문 편성 및 승급

- 레벨 2–5에서는 그 레벨에서 아직 통과하지 못한 새 메뉴를 먼저 편성한다. 무리 안에서 서로 다른 미통과 메뉴를 우선 배치한다. 한 번도 시도하지 않은 메뉴를 재도전 메뉴보다 우선하는 것을 기본값으로 둔다.
- 남는 자리에는 이전 레벨의 메뉴를 섞는다. 예를 들어 레벨 3 첫 무리는 생선구이, 쌀국수, 피자, 라면으로 구성할 수 있다. 무리 인원을 모두 채우는 것은 테스트용 기본값이다.
- 새 메뉴 각각에서 별 2개 이상을 한 번씩 받으면 승급 조건을 충족한다. 같은 메뉴의 반복 성공이나 이전 레벨 메뉴는 현재 레벨의 새 메뉴 통과 수를 늘리지 않는다.
- 무리 중간에 조건을 채우면 ‘레벨업 달성’을 표시한다. 현재 무리에는 입장 당시 제한 시간을 적용하고, 무리가 끝난 뒤 새 레벨을 적용한다.
- 레벨 5의 랍스터·조개구이·해물탕을 모두 통과하고 마지막 무리를 마치면 **‘혼밥 식당 마스터’** 엔딩이 열린다. 이후 자유 영업에서는 전체 15개 메뉴가 섞이고 최대 10명의 손님을 한 무리로 받는다. 자유 영업 시간은 레벨 5와 같은 40초를 초기값으로 둔다.

## 평가

| 결과 | 뜻 | 진행 영향 |
|---|---|---|
| ★★★ | 기본 완성 기준에 더해 정교한 조작 달성 | 메뉴 통과 |
| ★★ | 기본 완성 기준 충족 | 메뉴 통과 |
| ★ | 접시는 만들었으나 익힘·간·형태 등 기본 완성도 미달 | 서빙 성공, 해당 메뉴는 미통과 |
| 시간 초과 | 마감까지 서빙 입력 미접수 | 손님 이탈, 별점 없음 |

레벨 1 레시피와 세부 판정은 [FRD](FRD.md)를 따른다. 시간은 성공 여부에만 영향을 주고, 서빙 속도에는 보너스 별점을 주지 않는다.

## 후속 메뉴에서 검증할 대표 조작

아래는 레벨 2–5를 설계할 때 사용할 후보이며 레시피 확정 명세는 아니다.

| 레벨 | 조작 후보 |
|---|---|
| 2 | 라면은 물 끓이기와 면 삶기, 떡볶이는 끓이기와 저어 졸이기, 돈가스는 빵가루 입히기와 튀김 타이밍 |
| 3 | 생선구이는 뒤집고 굽기, 쌀국수는 면 삶기와 국물 붓기, 피자는 반죽 펴기·토핑·오븐 굽기 |
| 4 | K-치킨은 튀김과 양념 버무리기, 오징어볶음은 손질과 볶기, 스테이크는 시즈닝과 앞뒤 굽기 |
| 5 | 랍스터는 익히고 껍질 손질, 조개구이는 열리는 타이밍에 집기, 해물탕은 재료 순서와 끓이기 |

수전 세척, 껍질 손질, 칼질, 굽기, 끓이기, 삶기, 볶기, 시즈닝은 전체 버전의 조작 범위다. 감자 같은 식재료의 표면 껍질 벗기기는 후속 레시피에서 자연스러운 재료를 확정해 넣는다. 첫 버전에서는 달걀 껍질을 벌리는 조작을 구현한다.
