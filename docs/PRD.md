# PRD · 제품 요구사항

## 제품과 목표

〈채채의 혼밥 식당〉은 주문을 받고 음식을 만들어 직접 서빙하는 세로형 모바일 웹 게임이다. 홀에는 손님의 표정과 주문이 보이고, 주방에서는 손가락이 움직인 만큼 재료와 도구가 움직인다. 첫 플레이의 목표는 짧은 안내만으로 조작을 이해하고, 완성된 음식과 손님의 반응에서 만족감을 느끼게 하는 것이다.

- **플랫폼** 스마트폰 브라우저에서 링크로 진입한다. 세로형 화면이 기본이다.
- **플레이 방식** 한 손가락으로 플레이한다. 주문 선택, 손질, 조리, 플레이팅, 서빙, 평가까지 이어진다.
- **난도** 제한 시간이 있으나 빠른 서빙에 별점을 가산하지 않는다. 음식의 기본 완성도가 메뉴 통과 기준이다.

## 첫 플레이 버전 v0.1

| 우선순위 | 범위 |
|---|---|
| 필수 | 시작 화면, 손님과 주문 말풍선, 필수 계란후라이 트라이얼, 주방, 서빙, 평가, 시간 초과와 재도전 |
| 필수 | 레벨 1의 계란후라이·비빔밥·김밥, 최초 주문 순서, 미통과 메뉴 재주문, 메뉴별 통과 표시, 레벨 2 해금 |
| 필수 | 한 손가락 입력, 상황별 짧은 안내, 60초 타이머, 세로형 폰 화면, 실제 폰 검수 |
| 후속 버전 | 레벨 2–5 조리, 여러 손님의 주문을 담는 대기열 화면, 무리 순환, 마스터 엔딩, 자유 영업 |

첫 버전은 레벨 2 메뉴의 이름이 보이는 해금 화면에서 마무리한다. 트라이얼의 계란후라이와 레벨 1 계란후라이는 같은 조작을 사용하되 별개 주문이다.

## 완료 조건

1. 처음 온 사용자가 시작 화면에서 트라이얼을 통과하고 세 메뉴를 플레이해 레벨 2를 열 수 있다.
2. 한 번 실패해도 알맞은 경로로 복구한다. 트라이얼은 재도전하고, 레벨 1에서는 나머지 첫 메뉴를 경험한 뒤 미통과 메뉴에 다시 도전한다.
3. 조작의 핵심인 껍질 벌리기, 채소 씻기·썰기, 김밥 말기가 탭으로 단계를 건너뛰는 버튼 대신 실제 드래그·스와이프로 동작한다.
4. 타이머, 평가, 진행 표시가 규칙과 일치하며, 실제 폰에서 터치와 화면 전환을 확인한다. 상세 판정은 [QA](QA.md)를 따른다.

## 플레이테스트에서 볼 것

- 첫 안내를 보고 다음 동작을 이해했는지, 손가락이 조작 대상을 가렸는지, 스크롤이 조리와 충돌했는지 기록한다.
- 트라이얼 소요 시간, 메뉴별 첫 통과 여부, 막힌 단계와 손님 평가에 대한 이해를 기록한다. 수치 목표는 첫 관찰 뒤 결정한다.
