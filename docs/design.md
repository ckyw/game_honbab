# Game Design Guide · Visual & Camera Specification

사용자가 제공한 시각 가이드와 첫 세로형 웹 버전의 화면 적용 기준입니다.

## 1. 비주얼 스타일

- **아트**. 2.5D 캐주얼 툰 카툰 렌더링. 풍성한 볼륨감, 라운드 실루엣, 선명한 외곽선을 사용한다.
- **주방과 음식**. 웜 옐로우, 캐러멜 브라운, 딥 오렌지, 크림슨 레드의 고채도 온색을 중심으로 구성한다.
- **홀과 인테리어**. 우드 톤을 기본으로 웜 화이트와 올리브 그린을 보조색으로 사용한다.
- **질감과 조명**. 음식의 육즙과 기름기에 강한 화이트 스펙큘러를 둔다. 캐릭터는 부드러운 셀 셰이딩과 앰비언트 오클루전으로 둥근 입체감을 준다.

## 2. 듀얼 카메라

세로형 첫 버전은 홀과 주방을 전환하는 안을 기본값으로 둔다. 상하 분할을 적용할 때도 아래 두 시점을 유지한다.

### 2.1 홀 · 손님 정면 아이레벨

- **각도**. 0–10° 미세 부감의 아이레벨 정면. 주문 바나 테이블 너머의 손님 얼굴과 상반신이 중심이다.
- **정보 배치**. 손님 머리 위의 주문 말풍선과 인내도 상태가 서로 가려지지 않게 한다.
- **손님 다양성**. 어린이, 직장인, 미식가, 노인 등 체형과 헤어스타일 실루엣을 과장해 구별한다.

| 표정 단계 | 연출 |
|---|---|
| 등장과 기다림 | 밝은 미소, 주변을 둘러보기, 눈 깜빡임 |
| 지루함과 재촉 | 턱 괴기, 시계나 주방을 힐끔 보기, 가벼운 눈살 |
| 분노와 이탈 임박 | 붉어진 얼굴, 발 구르기, 부들부들 떨림 |
| 음식 서빙 | 양손을 들고 환호, 별과 하트 파티클, 눈물 찔끔 감동 표정 |

첫 버전은 대기 중인 손님을 차분한 표정으로 표시한다. 재촉과 이탈 임박 신호는 활성 주문의 남은 시간에만 연동하며, 화면 전환 방식에서는 주방 HUD에 해당 손님의 표정과 게이지를 축약해 보여준다. 성공 리액션의 강도는 별점에 맞추고, 시간 초과는 퇴장으로 표현한다.

### 2.2 주방 · 조리대 탑다운 하이 앵글

- **각도**. 60–75° 하향 부감의 탑다운 쿼터 뷰. 도마·팬·그릴·접시 등 활성 조작 영역을 화면 중앙에 크게 배치한다.
- **셰프 표현**. 손과 조리 도구를 중심으로 보여주고, 셰프가 등장할 경우 프레임 가장자리에 두어 조리대를 가리지 않게 한다.
- **도마**. 썰 때 리드미컬한 바운스와 굵은 카툰 텍스트 ‘툭’, ‘착’, ‘탁!’을 적용한다.
- **팬과 그릴**. 생고기 핑크 → 그릴 자국 → 골든 브라운 → 검은 탄 자국을 단계적으로 적용한다. 지글거리는 기름 방울과 연기, 불꽃을 더한다. 계란후라이에는 반투명 흰자 → 익은 흰자 → 타기 시작한 가장자리를 대응시킨다.
- **플레이팅**. 완성한 접시에 반짝이는 별 파티클과 부드러운 림라이트를 적용한다.

## 3. UI와 HUD

- **상단**. 홀에서는 각 손님 머리 위에 원형 또는 둥근 사각형 말풍선을 고정한다. 주방에서는 주문명과 남은 초를 상단에 표시한다. 인내도 게이지는 초록 → 주황 → 빨강으로 변하며 숫자와 상태 문구를 함께 사용한다.
- **중앙**. 팬, 도마, 접시의 터치 영역을 시각 요소에 맞춰 넉넉하게 둔다. 도구 옆 짧은 안내와 가이드로 손가락 방향을 표시한다.
- **하단**. ‘서빙하기’ 등 주요 동작을 엄지로 누르기 쉬운 위치에 두고 기기 안전 여백을 확보한다. 조리 완료가 가까울 때 ‘TAP!’ 인디케이터와 경고음 링을 시각적으로 활용한다. 실제 동작이 드래그인 단계에는 ‘옮기기!’처럼 맞는 문구를 사용한다.
- **한 손가락**. 말풍선, 손님 목록, 도구를 한 손가락으로 조작한다. 목표 영역이 조리 중 이펙트나 손가락에 가려질 때는 대상 바깥쪽에 하이라이트를 둔다.

## 4. 특수 효과와 피드백

- [ ] 조리 성공 시 슬로모션 0.1초와 가벼운 화면 흔들림. 연출 재생과 주문 시간 판정은 분리한다.
- [ ] 타는 경고 시 조리 기구 주변의 붉은 맥동 테두리.
- [ ] 콤보 달성 시 골드 코인과 칭찬 팝업 ‘PERFECT!’, ‘DELICIOUS!’. 콤보 발동 기준은 후속 단계에서 정의한다.
- [ ] 사운드를 꺼도 색, 게이지, 문구로 조리 상태를 알아볼 수 있다. 모션 감소 환경에서는 흔들림과 강한 점멸을 줄인다.

첫 플레이 버전에서 먼저 구현할 표현은 주문 말풍선, 손님의 기본 표정과 결과 반응, 팬 열기와 익힘·탄 상태, 조작에 반응하는 재료, 접시 완성 피드백이다. 미확정 효과와 소리는 [PLAN](PLAN.md)의 후속 마감 작업으로 관리한다.
